vim-html2jade
=============

[![Open in Hanzo](https://hanzo.app/badges/open-in-hanzo.svg)](https://hanzo.app/dev/open?repo=github.com/zeekay/vim-html2jade&ref=master&action=open) [![Edit with Hanzo](https://hanzo.app/badges/edit-with-hanzo.svg)](https://hanzo.app/dev/open?repo=github.com/zeekay/vim-html2jade&ref=master&action=edit)

Adds `Html2Jade` command which converts the current HTML buffer to Jade. Uses
[html2jade](http://https://github.com/donpark/html2jade) (so make sure to `npm
install -g html2jade` first).
